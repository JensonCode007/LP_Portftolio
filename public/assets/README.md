# Replaceable portfolio imagery

Add creative images at `public/assets/creatives/creative-01.png` through `creative-18.png`.
Add logo images at `public/assets/logos/logo-01.png` through `logo-16.png`. The site also accepts the same `logo-01.jpg` / `logo-01.jpeg` naming pattern (PNG takes priority if more than one exists).

For the desktop lanyard, add the portrait image at `public/assets/leon_profile.png`. It automatically falls back to the LP mark until that image is present.

Names and captions are managed in `data/portfolio.json`.
